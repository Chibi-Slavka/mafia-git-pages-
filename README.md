# MAFIA — GitHub Pages

Веб-приложение «Мафия» в тёмном noir-стиле. Клиент находится в `index.html` и публикуется как статический сайт; сетевой режим использует отдельный Socket.IO-сервер на Node.js, который можно развернуть на Render. Браузерная библиотека Socket.IO включена локально в `vendor/`, поэтому CDN не требуется. Несколько фоновых фотографий загружаются по HTTPS с Unsplash; если изображения недоступны, остаются градиентные подложки.

## Публикация на GitHub Pages

Клиент публикуется напрямую из корня этой ветки без сборщика и workflow. Для сетевых партий дополнительно разверни сервер на Render по инструкции ниже.

1. Открой **Settings → Pages**.
2. В разделе **Build and deployment → Source** выбери **Deploy from a branch**.
3. Выбери ветку `arena/49baeaa5-mafia-git-pages` и папку `/(root)`, затем нажми **Save**.
4. Дождись публикации. Для этого репозитория адрес сайта: <https://chibi-slavka.github.io/mafia-git-pages-/>.
5. Последующие push в эту ветку автоматически обновляют сайт.

`index.html` находится в корне репозитория — это точка входа GitHub Pages.

## Что работает без сервера

- локальный демонстрационный режим в одном браузере;
- создание комнаты, добавление ботов и локальная игра;
- чат в пределах доступного локального режима;
- профили и настройки, сохраняемые в браузере;
- роли, игровые фазы, действия, голосование и журнал, предусмотренные клиентом.

Локальные данные не синхронизируются между разными браузерами или устройствами.

## Сетевой сервер на Render

GitHub Pages публикует только клиент. Реализация Socket.IO-сервера протокола `Mafia-2026` находится в `server/index.js`; сервер управляет комнатами, игроками, ролями, фазами, таймерами, голосованием и чатом. Обмен игровыми сообщениями идёт через событие `mafia:message`; роли отправляются только их владельцам.

### Развёртывание

1. В Render открой **New → Blueprint** и подключи этот GitHub-репозиторий.
2. Выбери ветку `arena/49baeaa5-mafia-git-pages`. Render прочитает `render.yaml` и создаст Node.js Web Service `mafia-git-pages-server` в регионе Frankfurt. Команды сборки и запуска: `npm ci` и `npm start`; проверка состояния — `/health`.
3. После успешного deploy скопируй HTTPS-адрес сервиса из Render. В настройках игры укажи его без пути, например `https://mafia-git-pages-server.onrender.com`, если Render выдал именно этот домен. Клиент подключится к Socket.IO по пути `/socket.io`.
4. На сайте открой **Настройки → Подключиться к серверу**. Игрокам нужно подключиться к тому же адресу; создатель комнаты делится кодом с остальными.

На GitHub Pages адрес сервиса должен начинаться с `https://`; Socket.IO сам согласует защищённое соединение. Для локальной проверки сервера запусти `npm ci && npm start`; Socket.IO доступен по `http://localhost:10000` (путь `/socket.io`), а health check — по `http://localhost:10000/health`.

Список разрешённых источников по умолчанию включает GitHub Pages этого проекта и localhost. Для собственного домена добавь переменную Render `ALLOWED_ORIGINS` со списком origin через запятую, например `https://example.com,https://chibi-slavka.github.io`.

Комнаты хранятся в памяти процесса: перезапуск или новый deploy очищает активные лобби и партии. Сервер не использует учётные записи; идентификатор игрока создаётся в браузере, поэтому реализация подходит для дружеских партий, а не для защищённой соревновательной среды.

## Состав проекта

- `index.html` — клиентское приложение.
- `server/index.js` — Socket.IO-сервер Mafia-2026.
- `vendor/socket.io.min.js` — локальная браузерная библиотека Socket.IO.
- `render.yaml` — Render Blueprint для автоматического создания Web Service.
- `package.json` и `package-lock.json` — зависимости и команды сервера и тестов.

## Локальная проверка

Открой `index.html` в браузере. Для максимально похожего на Pages поведения можно запустить простой локальный HTTP-сервер из этой папки:

```bash
python -m http.server 8000
```

Затем открой `http://localhost:8000`. Для проверки серверных сценариев выполни `npm ci && npm test`.
